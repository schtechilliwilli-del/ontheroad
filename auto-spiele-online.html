Kurz einrichten

Trage oben in der Datei deine Firebase-Daten ein.

  1. Auf console.firebase.google.com Projekt anlegen.
  2. Realtime Database → erstellen → Europa → Testmodus.
  3. Regeln: { "rules": { ".read": true, ".write": true } }
  4. Web-App (</>) → firebaseConfig kopieren.
  5. Oben einfügen (inkl. databaseURL) & neu hochladen.
