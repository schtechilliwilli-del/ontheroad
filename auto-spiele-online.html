Kurz einrichten

Einmalig, dann läuft's. Trage oben in der Datei deine Firebase-Daten ein.

  1. Auf console.firebase.google.com ein kostenloses Projekt anlegen.
  2. Links Realtime Database → Datenbank erstellen → Standort Europa → im Testmodus starten.
  3. Bei Regeln eintragen: { "rules": { ".read": true, ".write": true } }
  4. Projektübersicht → Web-App hinzufügen (</>) → die firebaseConfig kopieren.
  5. Werte oben in dieser Datei zwischen den Markierungen einfügen (inkl. databaseURL!) und neu hochladen.

Danach lädst du die Seite bei GitHub Pages hoch und öffnest den Link auf jedem Handy.
